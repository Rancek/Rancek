# 👋 Sobre mí

¡Hola! Soy **Rancek**, artista enfocado en el mundo del **3D, la animación y la creación audiovisual**.

Durante mi formación universitaria desarrollé diferentes proyectos relacionados con **Modelado 3D, Animación, Lip Sync, Diseño de Personajes y Efectos Visuales (VFX)**.

Este perfil de GitHub funciona como mi **portafolio digital**, donde reúno una selección de trabajos realizados durante mis estudios y proyectos que representan mi proceso de aprendizaje y evolución artística.

Mi objetivo es continuar desarrollando mis conocimientos técnicos y creativos, especialmente dentro del mundo de la **animación y producción 3D**.

# 🎨 Áreas de trabajo

## 🧊 Modelado 3D

Desarrollo de modelos tridimensionales, personajes, objetos y estructuras.

Durante mi formación trabajé diferentes etapas del proceso:

**Referencia → Modelado → Esculpido → Topología → Texturizado → Iluminación → Render**

Algunas de las áreas desarrolladas incluyen:

- 👤 Modelado de personajes.
- 🏺 Modelado de objetos.
- 🏠 Modelado de estructuras.
- 🗿 Esculpido digital.
- 🕸️ Topología.
- 🎨 Texturizado.
- 💡 Iluminación.
- 🖼️ Renderizado.

---

## 🎬 Animación 3D

La animación es otra de las principales áreas desarrolladas durante mi formación.

He realizado diferentes ejercicios relacionados con:

- 🚶 Ciclos de caminata.
- 🏃 Ciclos de carrera.
- 🎭 Acting.
- 🧍 Movimiento corporal.
- ⏱️ Timing.
- 🔄 Poses y transiciones.
- 🙂 Expresiones.
- 🎬 Animación de personajes.

Mi proceso general de animación se basa en:

**Referencia → Blocking → Poses → Timing → Refinamiento → Animación final**

---

## 🗣️ Lip Sync

También he trabajado en ejercicios de **sincronización labial y actuación de personajes**.

El Lip Sync combina diferentes elementos de animación:

**Audio → Análisis → Fonemas → Poses de boca → Expresión → Acting → Animación**

Durante estos trabajos desarrollé conocimientos relacionados con:

- 👄 Sincronización labial.
- 🔤 Fonemas.
- 👀 Dirección de mirada.
- 🤨 Movimiento de cejas.
- 🙂 Expresiones faciales.
- 🎭 Acting.
- 🧍 Lenguaje corporal.
- ⏱️ Timing.

---

## ✨ Efectos Visuales — VFX

Otra de las áreas exploradas durante mis estudios fue la creación de **Efectos Visuales y composición digital**.

He desarrollado diferentes ejercicios relacionados con:

- ✨ VFX.
- 💥 Efectos visuales.
- 🎬 Composición digital.
- 🎥 Integración audiovisual.
- 💡 Iluminación.
- 🎨 Corrección visual.
- 🎞️ Edición.
- 🖼️ Postproducción.

El flujo general utilizado en estos proyectos fue:

**Material original → Efectos → Composición → Integración → Correcciones → Resultado final**
